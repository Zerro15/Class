# ClassFlow MVP SPEC

## Статусы занятий
- `scheduled` — запланировано
- `done` — проведено
- `canceled` — отменено

## Оплата
- `is_paid` — флаг оплаты
- `paid_amount` — сумма оплаты (>= 0)
- `paid_at` — дата оплаты (опционально)

## Домашка
- `text` — текст задания
- `link` — ссылка
- `is_sent` — отправлено ли
- `sent_at` — дата отправки

## Налог/комиссия
- В таблице `settings` хранится `tax_percent_default`
- При создании занятия значение копируется в `lesson.tax_percent`
